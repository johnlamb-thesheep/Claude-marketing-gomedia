GoMedia Marketing Assistance

How to use it

Talk to it like a colleague. It does the work, then waits for your OK.

1

Open Claude

Claude desktop app → Code tab → open the claude-marketing folder

2

Ask in plain words

Say the client, the project or agent, and what you need

3

Check and approve

It shows the result and asks before anything goes live or costs money

Things you can say

“Write 5 ad copies for LeadX seller leads”“Make a new launch video for Hougang Central”“How did Jared Tan’s ads do last week?”“Which ads are tired and need replacing?”“Give me an image prompt for a Thomson Reserve ad”“Add a dashboard for a new agent”
